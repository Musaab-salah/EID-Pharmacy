# 1. بدء التشغيل

## 1.1 تشغيل النظام لأول مرة

### الخطوة 1: تشغيل الخادم (Backend)
1. افتح الطرفية (Terminal)
2. انتقل لمجلد الخادم:
   ```
   cd eid_pharmacy_backend
   ```
3. ثبّت الحزم:
   ```
   pip install -r requirements.txt
   ```
4. نفّذ الترحيلات:
   ```
   python manage.py migrate
   ```
5. أدخل البيانات الأولية (اختياري لكن موصى به):
   ```
   python manage.py seed_data
   ```
6. شغّل الخادم:
   ```
   python manage.py runserver 8000
   ```
7. تأكد من ظهور رسالة: `Starting development server at http://127.0.0.1:8000/`

### الخطوة 2: تشغيل لوحة الإدارة
1. افتح طرفية جديدة
2. انتقل لمجلد لوحة الإدارة:
   ```
   cd frontend-admin
   ```
3. ثبّت الحزم:
   ```
   npm install
   ```
4. شغّل التطبيق:
   ```
   npm run dev
   ```
5. افتح المتصفح على: `http://localhost:5173/admin`

### الخطوة 3: تشغيل نقطة البيع
1. افتح طرفية ثالثة
2. انتقل لمجلد نقطة البيع:
   ```
   cd frontend-app
   ```
3. ثبّت الحزم:
   ```
   npm install
   ```
4. شغّل التطبيق:
   ```
   npm run dev
   ```
5. افتح المتصفح على: `http://localhost:5174/app`

## 1.2 تسجيل الدخول لأول مرة

- **البريد الإلكتروني**: `admin@eidpharmacy.local`
- **كلمة المرور**: `Admin123!`

استخدم نفس البيانات في لوحة الإدارة ونقطة البيع.

## 1.3 ترتيب الإعداد الموصى به

لبدء العمل بسلاسة، يُنصح بإعداد البيانات بالترتيب التالي:

1. **الفروع** — أضف فروع الصيدلية
2. **التصنيفات** — أضف تصنيفات المنتجات

6. **حسابات الدفع** — إن كنت تستخدم الدفع بالتحويل

# 2. أهداف الصفحات في النظام

كل صفحة في النظام لها هدف محدد. يظهر **هدف الصفحة** في أعلى كل صفحة لمساعدة المستخدم على فهم الغرض من استخدامها.

## 2.1 لوحة الإدارة (Admin)

| الصفحة | الهدف |
|--------|-------|
| **تسجيل الدخول** | تسجيل الدخول للوصول إلى لوحة الإدارة وإدارة النظام. |
| **لوحة التحكم** | عرض ملخص سريع لمبيعات اليوم والشهر ومراقبة أداء الصيدلية. |
| **المنتجات** | إدارة كتالوج المنتجات: إضافة، تعديل، حذف المنتجات وتحديد الفروع التي يتوفر فيها كل منتج. |
| **التصنيفات** | تنظيم المنتجات في تصنيفات (مثل: أدوية بوصفة، OTC، فيتامينات) لتسهيل البحث والتصفية. |
| **الدُفعات** | إدارة دفعات المخزون: كل دفعة تمثل كمية من منتج في فرع معين بتاريخ انتهاء، للنظام FEFO. |
| **المستخدمون** | إدارة المستخدمين وصلاحياتهم (مدير، صيدلي، كاشير) وربطهم بالفروع. |
| **الفروع** | إدارة فروع الصيدلية وعناوينها. |
| **العملاء** | قاعدة بيانات العملاء للبحث السريع عند البيع وربط الفواتير بالعملاء. |
| **حسابات الدفع** | إدارة حسابات التحويل البنكية والمحافظ الإلكترونية المستخدمة عند الدفع بالتحويل. |
| **المخزون** | مراجعة المخزون (مطابقة الكمية الفعلية بالنظام) وتعديله (إضافة، خصم، تحويل بين الفروع). |
| **الموردون** | إدارة الموردين وبيانات الاتصال بهم. |
| **فواتير المشتريات** | تسجيل فواتير المشتريات من الموردين لأغراض المحاسبة والتقارير. |
| **التقارير** | استخراج تقارير المشتريات، المبيعات، نقص المخزون، وقرب انتهاء الصلاحية. |

## 3.3 المنتجات (Products)

### عرض قائمة المنتجات
- جدول يعرض: **صورة المنتج**، الاسم، التصنيف، المورد، **الفروع**، مكان التصنيع، الباركود، السعر، سعر الشراء، الحد الأدنى
- أزرار **تعديل** و **حذف** لكل منتج
- أزرار **طباعة** و **تصدير PDF** لطباعة أو تصدير قائمة المنتجات بالكامل

### إضافة منتج جديد
1. انقر **إضافة**
2. املأ الحقول:
   - **التصنيف** (مطلوب): اختر من القائمة — يجب إضافة التصنيفات أولاً من صفحة التصنيفات
   - **المورد** (مطلوب): اختر من القائمة — يجب إضافة الموردين أولاً من صفحة الموردون
   - **الفروع (التي يتوفر فيها المنتج)** (اختياري): اختر فرعاً واحداً أو أكثر من القائمة المنسدلة — يُنشئ النظام تلقائياً دفعة أولية (كمية 0) لكل فرع محدد
   - **الاسم بالإنجليزي** (مطلوب)
   - **الاسم بالعربي** (مطلوب)
   - **مكان التصنيع**: بلد أو مكان المنشأ (مثال: مصر، ألمانيا)
   - **الباركود**: اختياري
   - **SKU**: اختياري
   - **السعر** (مطلوب): سعر البيع
   - **سعر الشراء** (مطلوب)
   - **الحد الأدنى للمخزون**: رقم للتنبيه عند نقص الكمية (0 = لا تنبيه)
   - **صورة المنتج**: اختر ملف صورة (JPG, PNG) — تظهر في نقطة البيع
3. انقر **OK** للحفظ

### تعديل منتج
1. انقر **تعديل** بجانب المنتج
2. عدّل الحقول المطلوبة (بما فيها الفروع)
3. لاستبدال الصورة: اختر ملف جديد من حقل "صورة المنتج"
4. انقر **OK**

### حذف منتج
- انقر **حذف** — سيُحذف المنتج نهائياً (تأكد من عدم وجود مبيعات أو مخزون مرتبط)

### طباعة وتصدير قائمة المنتجات
- **طباعة**: انقر **طباعة** لفتح نافذة جديدة بالجدول جاهز للطباعة (Ctrl+P)
- **تصدير PDF**: انقر **تصدير PDF** لتحميل ملف PDF يحتوي على قائمة المنتجات

## 3.5 الدُفعات (Batches)

كل دفعة تمثل كمية من منتج معين في فرع معين بتاريخ انتهاء محدد.

### إضافة دفعة
1. انقر **إضافة**
2. اختر **المنتج** و **الفرع**
3. أدخل **رقم الدفعة** (من الفاتورة أو الشحنة)
4. أدخل **تاريخ الانتهاء**
5. أدخل **الكمية** و **تكلفة الوحدة**
6. احفظ

### ملاحظة
- عند البيع، النظام يختار تلقائياً الدفعة الأقرب للانتهاء (FEFO)

## 3.9 حسابات الدفع (Payment Accounts)

تُستخدم عند الدفع بالتحويل في نقطة البيع.

### إضافة حساب
1. انقر **إضافة**
2. أدخل **الاسم بالعربي** و **الاسم بالإنجليزي**
3. أدخل **رقم الحساب** (IBAN أو رقم المحفظة)
4. اختر **نوع الحساب**: بنك أو محفظة إلكترونية
5. حدد **الحالة**: نشط / غير نشط
6. احفظ

### ملاحظة
- الحسابات النشطة فقط تظهر في نقطة البيع عند اختيار "تحويل إلى حساب"

## 3.10 الموردون (Suppliers)

1. انقر **إضافة**
2. أدخل الاسم بالعربي والإنجليزي، الهاتف، العنوان
3. احفظ

### الاستخدام

## 3.11 فواتير المشتريات (Purchase Invoices)

لتسجيل مشتريات من الموردين (لأغراض المحاسبة والتقارير).

### إضافة فاتورة شراء
1. انقر **إضافة**
2. أدخل **رقم الفاتورة** (مثال: INV-001)
3. اختر **تاريخ الشراء**
4. اختر **المورد** و **الفرع**
5. في قسم البنود:
   - لكل بند: اختر **المنتج**، أدخل **الكمية**، أدخل **سعر الشراء**
   - انقر **+ إضافة سطر** لإضافة بند آخر
6. انقر **OK** للحفظ

### ملاحظة
- فواتير المشتريات للتسجيل فقط — لا تُحدّث المخزون تلقائياً. استخدم **المخزون → تعديل المخزون** لإضافة الكميات.

## 3.12 المخزون (Inventory)

### أ) مراجعة المخزون (Inventory Audit)

للمطابقة بين الكمية في النظام والكمية الفعلية على الرف.

1. اختر **نوع المراجعة**: يومي / أسبوعي / شهري
2. اختر **الفرع** عبر القائمة المنسدلة ذات علامات الصح (✓):
   - **جميع الفروع**: انقر على الخيار لعرض دفعات كل الفروع
   - **فرع واحد**: ألغِ تحديد "جميع الفروع" ثم حدّد فرعاً واحداً
   - **عدة فروع**: ألغِ تحديد "جميع الفروع" ثم حدّد الفروع المطلوبة بواسطة علامات الصح
3. يتم تحميل الدُفعات تلقائياً بعد اختيار الفروع
4. في الجدول:
   - **الكمية في النظام**: الرقم المخزّن حالياً
   - **الكمية الفعلية**: أدخل العدد الذي عدَدته فعلياً
5. انقر **حفظ العدد** لتحديث المخزون (يُحفظ لكل فرع على حدة عند اختيار عدة فروع أو الكل)
6. **طباعة** و **تصدير PDF**: لطباعة أو تصدير جدول الجرد

### ب) تعديل المخزون (Stock Adjust)

قسم قابل للطي في أسفل الصفحة.

1. اختر **الدفعة** من القائمة
2. اختر **العملية**:
   - **إضافة مخزون**: لزيادة الكمية (مثلاً بعد استلام شحنة)
   - **خصم مخزون**: لإنقاص الكمية (تالف، هدر)
   - **تحويل مخزون**: لنقل كمية لفرع آخر — اختر **فرع الوجهة**
3. أدخل **الكمية**
4. انقر **تنفيذ**

## 3.13 التقارير (Reports)

### تقارير المشتريات
1. افتح تبويب **تقارير المشتريات**
2. اختر **نطاق التاريخ** (من - إلى)
3. اختياري: اختر **المورد** أو **المنتج**
4. انقر **تطبيق**
5. انقر **تصدير CSV** لتحميل الملف

### تقارير المبيعات
1. افتح تبويب **تقارير المبيعات**
2. اختر **نطاق التاريخ**
3. اختياري: اختر **الكاشير** أو **طريقة الدفع**
4. انقر **تطبيق**
5. انقر **تصدير CSV** لتحميل الملف

### تقرير نقص الكمية
1. افتح تبويب **أصناف قليلة المخزون**
2. اختياري: أدخل **حد مخصص** (مثلاً 5) لعرض كل المنتجات التي كميتها ≤ هذا الحد
3. أو اتركه فارغاً لاستخدام الحد الأدنى المُعرّف لكل منتج
4. انقر **تطبيق**
5. انقر **تصدير CSV**

### تقرير قرب انتهاء الصلاحية
1. افتح تبويب **قرب انتهاء الصلاحية**
2. يعرض تلقائياً الدُفعات التي تنتهي خلال 3 أشهر
3. انقر **تصدير CSV**

# 4. نقطة البيع (POS)

## 4.1 تسجيل الدخول

1. افتح `http://localhost:5174/app`
2. أدخل **البريد الإلكتروني** و **كلمة المرور** (نفس بيانات المستخدم من لوحة الإدارة)
3. انقر تسجيل الدخول

---

## 4.2 عملية البيع — خطوة بخطوة

### الخطوة 1: المنتجات (1 المنتجات)

1. **البحث**: اكتب اسم المنتج أو الباركود في شريط البحث
2. **التصنيفات**: اختر تصنيفاً لتصفية المنتجات
3. **إضافة للسلة**: انقر على بطاقة المنتج لإضافة وحدة واحدة
4. **السلة**: تظهر في الأعلى عدد المنتجات في السلة
5. **المنتجات غير المتاحة**: تظهر علامة "نفاد" ولا يمكن إضافتها
6. **المنتجات قليلة المخزون**: تظهر علامة "منخفض" (كمية ≤ 5)

#### اختصارات لوحة المفاتيح
- **F1**: الانتقال لخطوة المنتجات
- **F2**: الانتقال لخطوة العميل
- **F3**: الانتقال لخطوة الدفع

### الخطوة 2: العميل (2 العميل)

1. أدخل **اسم العميل** (مطلوب)
2. أدخل **رقم الجوال** (مطلوب)
3. انقر **بحث** للتحقق إن كان العميل مسجلاً — يتم استكمال الاسم تلقائياً
4. اختياري: أدخل **ملاحظات**
5. انقر **التالي**

### الخطوة 3: الدفع (3 الدفع)

1. راجع **الإجمالي النهائي** في الأعلى
2. اختر طريقة الدفع:

#### أ) نقدًا
- انقر **نقدًا**
- انقر **إتمام الدفع**

#### ب) تحويل إلى حساب
- انقر **تحويل إلى حساب**
- **اختر حساب التحويل** من القائمة (الحسابات المُضافة من لوحة الإدارة)
- **ارفع صورة إشعار التحويل** (JPG أو PNG) — **إلزامي**
- إذا لم ترفع الصورة واضغط "إتمام الدفع"، ستظهر رسالة تنبيه
- بعد رفع الصورة، انقر **إتمام الدفع**

### الخطوة 4: الفاتورة (4 الفاتورة)

1. يعرض ملخص الفاتورة
2. يمكن طباعة الإيصال عبر نافذة الطباعة في المتصفح (Ctrl+P)
3. انقر **بيع جديد** لبدء عملية بيع جديدة

## 4.3 قواعد البيع التلقائية

| القاعدة | الوصف |
|---------|-------|
| FEFO | يتم اختيار الدفعة الأقرب للانتهاء تلقائياً |
| منع المنتجات المنتهية | لا يمكن بيع منتجات منتهية الصلاحية |
| التحقق من المخزون | لا يمكن إضافة منتج غير متوفر |

---

## 4.4 واجهة نقطة البيع

- **دعم RTL**: الواجهة تتبنى الاتجاه من اليمين لليسار تلقائياً مع اللغة العربية
- **بطاقة المنتج**: تعرض الصورة، الاسم، السعر، الكمية المتاحة، مكان التصنيع
- **ملخص الطلب**: يعرض البنود، الإجمالي، الضريبة، الخصم، الإجمالي النهائي

# 4. دعم اللغة العربية والطباعة

## 5.1 تغيير اللغة

- في الشريط العلوي: انقر على **اللغة** واختر **العربية** أو **English**
- الواجهة تدعم **RTL** (من اليمين لليسار) تلقائياً عند اختيار العربية

## 5.2 الطباعة وتصدير PDF بالعربية

عند استخدام **طباعة** أو **تصدير PDF** في صفحة المنتجات أو المخزون:

- **النص العربي** يظهر بشكل صحيح (لا رموز غريبة)
- النظام يستخدم خط **Amiri** لدعم العربية واللاتينية
- يتم احترام اتجاه النص (RTL/LTR) حسب اللغة المختارة
- الطباعة: تُفتح نافذة جديدة ويُحمّل خط Amiri من الإنترنت
- تصدير PDF: الخط يُضمّن في الملف ولا يحتاج اتصالاً

## 5.3 الصفحات المدعومة

| الصفحة | طباعة | تصدير PDF |
|--------|-------|-----------|
| المنتجات | ✓ | ✓ |
| مراجعة المخزون | ✓ | ✓ |

# 6. حل المشكلات

## 6.1 لا يمكن تسجيل الدخول
- تأكد من تشغيل الخادم (Backend) على المنفذ 8000
- تحقق من البريد وكلمة المرور
- نفّذ `python manage.py seed_data` لإعادة إنشاء المستخدم الافتراضي

## 6.2 الصور لا تظهر
- تأكد من تشغيل الخادم
- تأكد من وجود مجلد `media` في مجلد الخادم
- تحقق من إعدادات `MEDIA_URL` و `MEDIA_ROOT` في الإعدادات

## 6.3 لا تظهر حسابات التحويل في نقطة البيع
- تأكد من إضافة الحسابات من **لوحة الإدارة → حسابات الدفع**
- تأكد من أن الحساب **نشط** (is_active = true)

## 6.4 خطأ عند إنشاء الطلب
- تأكد من رفع صورة الإشعار عند الدفع بالتحويل
- تأكد من اختيار حساب التحويل
- تحقق من اتصال الشبكة بالخادم

## 6.5 التقارير فارغة
- تحقق من نطاق التاريخ
- تأكد من وجود بيانات (مبيعات، مشتريات، دفعات) في الفترة المحددة

---

## 6.6 الطباعة أو PDF تظهر رموزاً غريبة للعربية

- تأكد من اتصال الإنترنت عند الطباعة (لتحميل خط Amiri)
- تصدير PDF لا يحتاج اتصالاً — الخط مُضمّن في الملف
