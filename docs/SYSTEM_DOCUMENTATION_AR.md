# وثائق نظام صيدلية عيد — دليل شامل

## نظرة عامة

نظام صيدلية عيد هو نظام إدارة صيدلية متكامل يتكون من:
- **لوحة الإدارة (Admin)**: لإدارة المنتجات، المخزون، التقارير، والمستخدمين
- **نقطة البيع (POS)**: لتنفيذ المبيعات للعملاء
- **واجهة برمجة التطبيقات (API)**: للربط بين الواجهات

---

## 1. التشغيل والإعداد

### المتطلبات
- Python 3.x
- Node.js و npm
- قاعدة بيانات SQLite (مضمنة)

### تشغيل الخادم (Backend)
```bash
cd eid_pharmacy_backend
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_data
python manage.py runserver 8000
```
- عنوان API: `http://localhost:8000/api/`

### تشغيل لوحة الإدارة
```bash
cd frontend-admin
npm install
npm run dev
```
- الرابط: `http://localhost:5173/admin`

### تشغيل نقطة البيع
```bash
cd frontend-app
npm install
npm run dev
```
- الرابط: `http://localhost:5174/app`

### بيانات الدخول الافتراضية
- البريد: `admin@eidpharmacy.local`
- كلمة المرور: `Admin123!`

## 2. لوحة الإدارة (Admin Panel)

### 2.1 لوحة التحكم (Dashboard)
- ملخص سريع للنظام
- عرض إحصائيات أساسية

### 2.2 المنتجات (Products)
- **الموقع**: القائمة الجانبية → المنتجات
- **الوظائف**:
  - إضافة منتج جديد
  - تعديل منتج
  - حذف منتج
- **الحقول**:
  - التصنيف (مطلوب)
  - المورد (مطلوب)
  - الاسم بالعربي والإنجليزي
  - مكان التصنيع (بلد أو مكان المنشأ)
  - الباركود، SKU
  - السعر، سعر الشراء
  - الحد الأدنى للمخزون (لتنبيهات نقص الكمية)
  - صورة المنتج

### 2.3 التصنيفات (Categories)
- إدارة تصنيفات المنتجات
- الحقول: الكود، الاسم بالعربي، الاسم بالإنجليزي

### 2.4 الدُفعات (Batches)
- إدارة دفعات المنتجات
- كل دفعة مرتبطة بمنتج وفرع
- الحقول: رقم الدفعة، تاريخ الانتهاء، الكمية، تكلفة الوحدة

### 2.5 المستخدمون (Users)
- إدارة المستخدمين (أدمن، صيدلي، كاشير)
- ربط المستخدم بالفرع
- البريد الإلكتروني وكلمة المرور

### 2.6 الفروع (Branches)
- إدارة فروع الصيدلية
- الاسم والعنوان

### 2.7 العملاء (Customers)
- إدارة بيانات العملاء
- الاسم، الهاتف، البريد

### 2.8 حسابات الدفع (Payment Accounts)
- حسابات التحويل البنكية
- تُستخدم عند الدفع بالتحويل
- الحقول: الاسم، رقم الحساب، نوع الحساب (بنك/محفظة)

### 2.9 الموردون (Suppliers)
- إدارة الموردين
- الحقول: الاسم، الهاتف، العنوان

### 2.10 فواتير المشتريات (Purchase Invoices)
- تسجيل فواتير الشراء
- إضافة فاتورة: رقم الفاتورة، التاريخ، المورد، الفرع
- إضافة بنود: المنتج، الكمية، سعر الشراء

### 2.11 المخزون (Inventory)

#### مراجعة المخزون (Inventory Audit)
- **الموقع**: القائمة الجانبية → المخزون
- **الوظائف**:
  - فلترة حسب نوع المراجعة: يومي / أسبوعي / شهري
  - فلترة حسب الفرع
  - عرض جدول الدُفعات مع:
    - الكمية في النظام
    - **الكمية الفعلية** (قابلة للتعديل)
  - حفظ العدد لتحديث المخزون وفق العدد الفعلي

#### تعديل المخزون (Stock Adjust)
- قسم قابل للطي في نفس الصفحة
- الوظائف: إضافة مخزون، خصم مخزون، تحويل مخزون بين الفروع

### 2.12 التقارير (Reports)

#### تقارير المشتريات
- فلترة: نطاق التاريخ، المورد، المنتج
- عرض: تاريخ الشراء، رقم الفاتورة، المورد، المنتجات، الكميات، الأسعار، الإجمالي
- تصدير CSV

#### تقارير المبيعات
- ملخص يومي وشهري
- فلترة: نطاق التاريخ، الكاشير، طريقة الدفع (نقدًا / تحويل)
- عرض: تاريخ البيع، رقم الفاتورة، المنتجات، الكميات، الأسعار
- تصدير CSV

#### تقرير نقص الكمية
- منتجات تحت الحد الأدنى
- عرض: المنتج، الكمية الحالية، الحد الأدنى
- إمكانية تحديد حد مخصص

#### تقرير قرب انتهاء الصلاحية
- دفعات تنتهي خلال 3 أشهر
- عرض: المنتج، رقم الدفعة، تاريخ الانتهاء، الكمية المتبقية
- تصدير CSV

## 3. نقطة البيع (POS)

### 3.1 تسجيل الدخول
- البريد الإلكتروني وكلمة المرور
- نفس بيانات المستخدمين في لوحة الإدارة

### 3.2 عملية البيع

#### الخطوة 1: المنتجات
- اختيار المنتجات من القائمة
- البحث بالاسم أو الباركود
- تصفية حسب التصنيف
- عرض كل منتج: الصورة، الاسم، السعر، الكمية المتاحة
- إضافة للسلة بالنقر على المنتج

#### الخطوة 2: العميل
- إدخال بيانات العميل (اختياري)
- البحث بالهاتف

#### الخطوة 3: الدفع
- **طريقتان فقط**:
  1. **نقدًا**: إتمام الدفع مباشرة
  2. **تحويل إلى حساب**:
     - اختيار حساب التحويل من القائمة
     - **إرفاق صورة إشعار التحويل إلزامي** (JPG أو PNG)
     - لا يمكن إتمام الدفع دون رفع الصورة

#### الخطوة 4: الفاتورة
- عرض ملخص الفاتورة
- طباعة الإيصال (إذا متوفر)

### 3.3 قواعد البيع
- **FEFO**: يتم اختيار الدفعة الأقرب للانتهاء تلقائيًا
- **منع المنتجات المنتهية**: لا يمكن بيع منتجات منتهية الصلاحية
- **التحقق من المخزون**: لا يمكن إضافة منتج غير متوفر

## 4. واجهة برمجة التطبيقات (API)

### 4.1 المصادقة
- JWT (JSON Web Token)
- مسار الحصول على التوكن: `POST /api/auth/token/`
- إرسال التوكن في الهيدر: `Authorization: Bearer <token>`

### 4.2 المسارات الرئيسية

| المسار | الوصف |
|--------|-------|
| `/api/branches/` | الفروع |
| `/api/categories/` | التصنيفات |
| `/api/products/` | المنتجات |
| `/api/batches/` | الدُفعات |
| `/api/users/` | المستخدمون |
| `/api/customers/` | العملاء |
| `/api/suppliers/` | الموردون |
| `/api/payment-accounts/` | حسابات الدفع |
| `/api/payment-accounts/active/` | الحسابات النشطة فقط |
| `/api/purchases/` | فواتير المشتريات |
| `/api/sales/` | فواتير المبيعات |
| `/api/orders/create/` | إنشاء طلب جديد |
| `/api/inventory/adjust/` | تعديل المخزون |
| `/api/inventory/audit/batches/` | قائمة الدُفعات للمراجعة |
| `/api/inventory/audit/save/` | حفظ العدد الفعلي |

### 4.3 تقارير API

| المسار | المعاملات | الوصف |
|--------|-----------|-------|
| `/api/reports/purchases/` | date_from, date_to, supplier_id, product_id | تقرير المشتريات |
| `/api/reports/sales/` | date_from, date_to, cashier_id, payment_method | تقرير المبيعات |
| `/api/reports/low_stock/` | threshold (اختياري) | نقص الكمية |
| `/api/reports/expiring/` | days (افتراضي 90) | قرب الانتهاء |
| `/api/reports/daily_sales/` | — | مبيعات اليوم |
| `/api/reports/monthly_sales/` | — | مبيعات الشهر |

## 5. هيكل قاعدة البيانات

### الجداول الرئيسية
- **Branch**: الفروع
- **User**: المستخدمون
- **Category**: التصنيفات
- **Supplier**: الموردون
- **Product**: المنتجات (مع التصنيف، المورد، الصورة، مكان التصنيع)
- **Batch**: الدُفعات (مع المنتج، الفرع، تاريخ الانتهاء)
- **Customer**: العملاء
- **PaymentAccount**: حسابات التحويل
- **SaleInvoice**: فواتير المبيعات
- **SaleLine**: بنود فواتير المبيعات
- **PurchaseInvoice**: فواتير المشتريات
- **PurchaseLine**: بنود فواتير المشتريات
- **StockCountLog**: سجل مراجعات المخزون
